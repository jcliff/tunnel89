📖 About This Game

This is a tunnel racing game written in 68000 assembly language back in 2000. Navigate your car through an ever-scrolling tunnel, avoiding the walls as they shift left and right. Test your reflexes across three difficulty levels!

Game Files:
  • tunnel.89z - Compiled TI-89 program (ready to run!)
  • tunnel.asm - Original 68K assembly source code
  • SPRITE.HUF - Huffman-compressed title screen
🚀 LAUNCH TI-89 EMULATOR
⬇️ Download tunnel.89z (for TiEmu or real hardware)

🎮 How to Load and Play

  1. Click the LAUNCH TI-89 EMULATOR button above
  2. Wait for the calculator to boot (you'll see the PedroM screen)
  3. The emulator uses PedroM, an open-source TI-89 operating system
  4. To load the game:
    • Method 1: Use the emulator's built-in file transfer feature (if available)
    • Method 2: Look for a "Load Program" or "Link" option in the emulator
    • File to load: tunnel.89z (located in the root directory)

🕹️ Game Controls

  • Left/Right Arrows: Move your car left and right
  • ESC: Exit to menu
  • ENTER: Start game from menu
  • F1 (or ON): Pause game
  • +/- (Up/Down Arrows on menu): Adjust difficulty

⚙️ Game Features

  • Three difficulty levels: Easy, Medium, Hard
  • High score table with top 4 racers per difficulty
  • Dynamic tunnel generation with randomized movements
  • Score tracking (1 point per 40 frames survived)
  • Collision detection
  • Custom sprite graphics

💻 Technical Details

🔧 Alternative: Manual Transfer

If the web emulator doesn't support direct file loading, you can:

  1. Download TiLP (TI Link Program) for your OS
  2. Get a TI-89 desktop emulator like TiEmu
  3. Use TiLP to transfer tunnel.89z to the emulator
  4. Run the program from the VAR-LINK menu

📚 About the Code

This project showcases classic calculator game development techniques:

  • Direct framebuffer manipulation (160×100 monochrome display)
  • Efficient scrolling algorithms (copies screen data down 1 pixel per frame)
  • Assembly-optimized sprite rendering with masking
  • Compressed graphics (Huffman encoding for title screen)
  • Hardware keyboard scanning (direct port access)

Check out tunnel.asm to see the full commented source code!
