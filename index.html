📖 About This Game

This is a tunnel racing game written in 68000 assembly language back in 2000. Navigate your car through an ever-scrolling tunnel, avoiding the walls as they shift left and right. Test your reflexes across three difficulty levels!

Game Files:
  • tunnel.89z - Compiled TI-89 program (ready to run!)
  • tunnel.asm - Original 68K assembly source code
  • SPRITE.HUF - Huffman-compressed title screen

⚠️ IMPORTANT: DoorOS Required!

This game (v1.6) requires DoorOS, a kernel for TI-89 that allows assembly programs with direct hardware access. The web-based emulator below uses PedroM (open-source OS) which is NOT compatible with DoorOS programs.

To actually play this game, use TiEmu desktop emulator with TI-89 ROM + DoorOS kernel.

🚧 NEW: Nostub Conversion (Work in Progress)

We're converting the game to a "nostub" program! This will allow it to run on stock AMS (official TI-89 OS) without requiring DoorOS or any kernel.

🎮 How to Actually Play This Game

Recommended: TiEmu Desktop Emulator

  1. Install TiEmu:
    • Ubuntu/Debian: sudo apt-get install tiemu
    • macOS: brew install tiemu
    • Windows: Download from lpg.ticalc.org/prj_tiemu
  2. Get TI-89 ROM: You need a ROM dump from a real TI-89 (legal if you own one)
  3. Install DoorOS kernel: Download from ticalc.org and install via TiEmu
  4. Load tunnel.89z: File → Send file to TI → Select tunnel.89z
  5. Run the game: Press 2nd + - (VAR-LINK), find "tunnel", press ENTER

Why the Web Emulator Won't Work

The web emulator uses PedroM (open-source TI-89 OS) for legal reasons. However, this game was compiled for:

  • doorsos.h - DoorOS kernel API
  • Direct hardware access ($4C00 framebuffer, $600018 keyboard port)
  • DoorOS-specific memory layout and function calls

PedroM and DoorOS are incompatible, so the .89z file won't run on the web emulator.

📱 Or Use Real Hardware!

If you have an actual TI-89 calculator:

  1. Install TI-Connect from Texas Instruments
  2. Install DoorOS kernel on your calculator
  3. Transfer tunnel.89z via USB
  4. Run from VAR-LINK!

🕹️ Game Controls

  • Left/Right Arrows: Move your car left and right
  • ESC: Exit to menu
  • ENTER: Start game from menu
  • F1 (or ON): Pause game
  • +/- (Up/Down Arrows on menu): Adjust difficulty

⚙️ Game Features

  • Three difficulty levels: Easy, Medium, Hard
  • High score table with top 4 racers per difficulty
  • Dynamic tunnel generation with randomized movements
  • Score tracking (1 point per 40 frames survived)
  • Collision detection
  • Custom sprite graphics

🔧 Alternative: Manual Transfer

If the web emulator doesn't support direct file loading, you can:

  1. Download TiLP (TI Link Program) for your OS
  2. Get a TI-89 desktop emulator like TiEmu
  3. Use TiLP to transfer tunnel.89z to the emulator
  4. Run the program from the VAR-LINK menu

📚 About the Code

This project showcases classic calculator game development techniques:

  • Direct framebuffer manipulation (160×100 monochrome display)
  • Efficient scrolling algorithms (copies screen data down 1 pixel per frame)
  • Assembly-optimized sprite rendering with masking
  • Compressed graphics (Huffman encoding for title screen)
  • Hardware keyboard scanning (direct port access)

Check out tunnel.asm to see the full commented source code!
